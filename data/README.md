# Dataset source and attribution

This folder contains the SMS Spam Collection archive obtained from the UCI Machine Learning Repository.

- Dataset page: https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection
- Dataset DOI: https://doi.org/10.24432/C5CC84
- Citation: Almeida, T. & Hidalgo, J. (2011). *SMS Spam Collection* [Dataset]. UCI Machine Learning Repository.
- License listed by UCI: Creative Commons Attribution 4.0 International (CC BY 4.0). The dataset is shared here with attribution to UCI and the dataset authors; the project code has no license declaration and is not covered by the dataset license.

The archive also contains the source dataset readme. The data are historical English SMS examples and may include sensitive message content; the repository therefore excludes generated row-level prediction and error files that repeat message text.
